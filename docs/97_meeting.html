26/09/11 - SUAS?

Camille & Sylvain

Following discussions about SUAS’s addition to the dataset, we decided to remove the delta linear regression that linked the plots together in a hyperlaw. Instead, we will perform post hoc linear regression, first quickly and then with uncertainty transmission. Doing so, we hope that SUAS won’t interfere with other super sites, such as Paracou. The analysis of the level of indetermination should be maintained for discussion purposes. The message seems to indicate a positive relationship when not accounting for rarefaction, suggesting an artefact from the increasing number of stems, but there is still a slight positive effect when accounting for it (to check if still the case). The results and discussion will be enriched by the spatial sensitivity analysis of Paracou and Mbaiki, which should be updated with post hoc linear regression with uncertainty transmission for consistency.
